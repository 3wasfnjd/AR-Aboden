# مختبر الماء AR — نسخة أولية غير مرتبطة بالرئيسية

الرابط المباشر: `https://3wasfnjd.github.io/AR-Aboden/tools/water-ar/`

حوض فوق سطح (ليس حفرة في الأرض)، تموجات باللمس، سحب كرة، وتصغير/تكبير/تدوير. وضع AR يستخدم نفس عائلة محرك XR8 المستخدمة في المستودع. وضع 3D مستقل للمقارنة ولا يفتح الكاميرا. هذه الصفحة عامة بالرابط المباشر؛ عدم ربطها بالرئيسية و`noindex` ليسا تحكمًا في الوصول.

## التشغيل

ابدأ بالجودة الخفيفة. اختر الكاميرا واسمح بها، امسح الأرض، تحقق من مستوى المعاينة ثم اضغط «ثبّت الحوض». وضع الأرضية يستخدم المستوى التقديري `y=0` للتتبع. خيار الطاولة يطلب ست نقاط داعمة على الأقل في رقعة أفقية؛ لا يقبل نقطة منفردة. عند ضعف التتبع يختفي الحوض مؤقتًا ويُحفظ موضعه. النقل يحتاج زر «نقل الحوض»؛ لا يُعاد ربطه بالكاميرا.

## المصدر والتنفيذ

- Three.js `0.185.1` عبر import map، دون تعديل نسخة أي صفحة أخرى.
- محرك XR8 من `@8thwall/engine-binary@1`، نفس قناة مشروع AR-Aboden. يُحمّل فقط بعد طلب AR.
- محرك الماء مستورد من `interactive-pool-volume/water-volume-system.js` عند commit `d1cb23dcce6ea8ee4a60f6159daeb79d4b511dba` في مستودع scottstts. لا يوجد استبدال للمحاكاة بمقطع فيديو أو مؤثر تموج صوري.
- `pool.js` يعزل الحالة الرسومية للتمريرات خارج الشاشة، ويحوّل موضع العين والكرة إلى إحداثيات الحوض بعد التثبيت والتحجيم والتدوير. لا يُرسم أي غطاء خلفية فوق كاميرا XR8.
- خامة البلاط وبيئة الانعكاس مولدتان محليًا. الانعكاسات ليست من الغرفة الحقيقية، والإضاءة ثابتة وليست قياسًا للغرفة.
- جودة خفيفة: شبكة محاكاة 128²، سطح 80×80، caustics بدقة 256². الجودة الأعلى: 256² / 128×128 / 512².
- المحاكاة بخطوة ثابتة 1/120 ثانية مع حد ست خطوات للاستدراك لكل تحديث وطابور لمس محدود. يتطلب الجهاز WebGL2 وهدف Half-Float صالحًا؛ يعرض رسالة عند فشل ذلك.

## التحقق

`node --test tools/water-ar/tests.mjs`

اختبارات منطق التثبيت والرقع الأفقية، رفض نقاط الجدار والتتبع القديم، حفظ القفل بعد حركة الكاميرا وفقدان التتبع، وفحوص عقد دمج ثابتة. لا تثبت اختبارات Node صحة رسوم GPU أو ثبات SLAM على جهاز فعلي.

يلزم اختبار iPhone/Safari: فتح الكاميرا، ظهور الماء، التثبيت والدوران حول الحوض، تموجات اللمس بعد تدوير/تكبير الحوض، سحب الكرة، الخلفية/العودة للتطبيق، جودة الأداء، والمقارنة مع المعاينة. لا يوجد حجب بالأثاث الحقيقي أو انعكاس حي للغرفة في هذه النسخة.

لم تُعدّل الرئيسية أو صفحة الليزر أو أداة ILD أو أي تجربة قائمة. لا تضف بطاقة للرئيسية قبل اعتماد الاختبار.
