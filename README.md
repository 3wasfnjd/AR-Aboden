# AR-Aboden — مختبر عبودين للواقع المعزز

## فكرة المستودع
مجموعة تجارب وألعاب تفاعلية للمتصفح، تجمع الواقع المعزز عبر كاميرا الجهاز وتجربة مستقلة للكتابة على الرمل.

## الخدمات والمزايا
- تجارب التفحيط، صيد المناطيد، الرعب، كرة السلة والرماية.
- عروض ليزر وحرب ألوان داخل المكان.
- تركيب الصور والفيديو وضبط الحجم والدوران والشفافية.
- الكتابة والرسم على الرمل ومسحه بموجة، دون كاميرا؛ تتطلب هذه التجربة WebGPU.
- دعم WebXR على الأجهزة المتوافقة، مع تجارب كاميرا بديلة بحسب الجهاز والمتصفح.
