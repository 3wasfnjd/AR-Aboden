# AR-Aboden

مختبر Web AR للجوال يعمل مباشرة من المتصفح ويُستضاف على GitHub Pages.

## التجربة الأولى

- فتح كاميرا الجوال.
- تتبع علامة **HIRO** باستخدام AR.js.
- عرض بوابة/مجسم ثلاثي الأبعاد متحرك فوق العلامة.
- زر تفاعل لتفعيل طاقة المجسم.
- واجهة عربية مهيأة للجوال.

## التشغيل

1. افتح رابط GitHub Pages للمستودع من الجوال.
2. اسمح بالوصول إلى الكاميرا.
3. افتح `marker.html` على شاشة ثانية أو اطبع علامة HIRO.
4. وجّه الكاميرا إلى العلامة.
5. عند ظهور المجسم اضغط **فعّل الطاقة**.

## التقنية

- A-Frame 1.6.0
- AR.js 3.4.8
- GitHub Pages
- لا يحتاج تثبيت تطبيق

> هذه النسخة Prototype للتحقق من التتبع على الجوال قبل إضافة موديلات GLB أو منطق لعبة كامل.
